# Web 产品与全链路验收：调试与常见故障

- 上传停在 0%：确认是否收到 XHR upload progress、预签名地址 CORS、过期时间和 part URL。
- 上传 100% 但没有任务：检查 complete 请求和幂等键；对象存在不等于业务已接收。
- SSE 反复连接：检查 Last-Event-ID/sequence、代理缓冲、心跳和 CORS；轮询恢复不能丢失终态。
- 刷新后状态消失：状态是否只保存在 Pinia；业务事实必须从后端重新读取。
- 引用抽屉 403：先确认是否正常撤权或 Manifest 换版，不要复用先前缓存正文。
- 页面显示 Zod 错误：前后端契约已漂移，先更新 OpenAPI/Schema，不要用类型断言跳过。
- E2E 严格模式冲突：定位器应锚定语义区域或 role，不能用 `.first()` 掩盖真正的重复交互控件；纯状态重复可以限定区域。
