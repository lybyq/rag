# Web 产品与全链路验收：信息架构

```text
AppShell
├─ 运营总览 / 知识空间 / 任务中心 / 审核台
├─ 知识问答 / 检索测试 / 评测中心
└─ 运行健康 / 审计导出 / 系统配置

Route View -> Feature Workbench -> Composable -> API Service -> platform/query API
                                  ↘ SSE，失败后带游标轮询恢复
```

问答台把会话、消息、公开 Run 阶段、引用预览和反馈分开。服务端只返回可公开阶段，不返回模型私有思维链、系统 Prompt 或隐藏候选。检索测试台同样只展示排名和剔除原因摘要，候选正文仍受引用 API 二次鉴权。

上传使用“先申请会话、浏览器直传、再完成确认”的三段式协议。任务中心订阅的是后端 Job 事实；刷新后从 API 恢复，不依赖浏览器内存。
