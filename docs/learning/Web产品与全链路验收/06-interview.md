# Web 产品与全链路验收：面试追问

## 为什么处理进度不能前端插值？

解析、OCR、Embedding 和发布耗时不可预测，插值会向用户展示不存在的成功。后端 Job 事实可刷新恢复、可审计，也能准确给出失败和重试建议。

## 为什么 Element Plus X 要 Adapter？

Adapter 把第三方 props、事件和版本变化收敛成项目自己的 BubbleList、Sender、Thinking 契约。业务页只依赖内部语义，升级影响面可由少量组件测试控制。

## SSE 为什么还要轮询？

企业代理、网关和浏览器休眠会断开长连接。SSE 提供低延迟，按 sequence 的轮询提供一致性恢复；PG 是最终事实源。

## 为什么引用每次打开都鉴权？

答案生成时有权限不代表查看时仍有权限。撤权、文档归档和 Manifest 切换都可能发生，引用正文属于受保护数据，必须按当前身份复核。

## 为什么前端仍需 Zod？

TypeScript 只约束编译期，网络响应是未知输入。运行时 Schema 可以在契约漂移处明确失败，避免错误数据继续污染 UI 状态。
