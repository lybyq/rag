# 评测与生产可靠性：面试追问

## 为什么 PR Golden 和真实离线评测都要有？

PR fixture 快且确定，适合阻止核心规则退化；真实评测覆盖模型、Prompt、检索 Profile 和数据分布。只有前者会漏掉供应商和数据漂移，只有后者反馈慢且成本高。

## 为什么保存方差和失败样本？

均值会掩盖少数极差样本，而权限泄漏即使只发生一次也不可接受。方差用于发现不稳定，失败码用于按根因聚类和重放。

## Deadline 和 timeout 有什么区别？

Deadline 是整条请求还能花多少时间，timeout 是某一次远程尝试的上限。重试必须服从剩余 Deadline，否则每层重试相乘形成延迟爆炸。

## 为什么 Redis 故障时查询 fail-closed？

流控状态不可知时继续放行可能击穿模型和数据库。企业知识问答通常可短暂不可用但不能诱发全局雪崩；健康检查和告警负责快速恢复。

## 为什么不直接备份 Milvus？

检索向量是由版本化 Chunk、Embedding revision 和 Manifest 推导的索引。把 PG/MinIO 作为事实源，可验证地重建比恢复一个语义可能不一致的索引快照更安全。
